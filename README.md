# ほっぽさん

住宅購入とライフプランを一緒に考える、スマートフォン向けの家計アプリです。
「私たちの人生設計では、いくらの住宅を買うのが無理がないのか」を、毎月の家計シミュレーションから答えます。

- 5画面（ホーム / FP / お家比較 / ローン / メモ）、下部ナビ固定、通常操作で縦横スクロールなし
- 計算はすべて端末内。入力は自動保存（IndexedDB）、JSONの書き出し・読み込み、1日1回の自動バックアップ
- PWA（ホーム画面に追加・オフライン動作）

**アプリを開く**: https://sprintershota01172-collab.github.io/HOP/

## 画面

| 画面 | できること |
|---|---|
| ホーム | 適正住宅予算（標準）、安心・標準・注意のものさし、推奨借入額、毎月の住宅関連支出、購入後の生活余力、貯蓄の見込み、候補住宅の上位 |
| FP | 将来の家計（月の収支の円グラフ／年の収支／資産の推移、5・10・20・30年後・退職時・老後への切り替え）、ライフプランの入力（収入・貯蓄・子供・生活費・保険・NISA・目標・イベント・育休時短・住まい・前提・根拠） |
| お家比較 | 2件を並べて比較、重み付けしたランキング（お金の評価と住み心地・好みを分けて表示、理由つき）、住宅ごとの家計への影響 |
| ローン | ①借りられる目安 ②無理なく返せる推奨額 ③希望額 を区別、毎月・総返済・利息・完済年齢・返済負担率、金利上昇・収入減・期間変更の比較、返済予定表 |
| メモ | 共通・住宅ごと・打ち合わせ・気になる点・確認事項・次回予定、ワンタップ整理（端末内のルールで分類・並べ替え） |

## 採用したFP計算ロジック

### 1. 月次シミュレーション（`src/engine/simulate.ts`）

入力した月から、最も若い人が設定年齢（初期 95歳）になる月まで、毎月の収支と残高を計算します。

```
現金(月末) = 現金(前月末) + 収入 − 支出 − 投資の積立 + 投資の取崩し − 売却時の税
投資(月末) = 投資(前月末) + 運用益 + 積立 − 取崩し
```

- **収入**: 手取り月収（毎年4月に昇給）、賞与（6月・12月、直近6か月の勤務割合で按分）、退職金、年金（受給開始から、物価−0.5%で改定）、児童手当、育休・時短の給付、イベント収入、保険の受取金、住宅ローン控除（有効時のみ）
- **支出**: 生活費（毎年1月に物価上昇を反映、全員退職後は老後の生活費に切替）、子供の生活費加算、教育費（学年・4月始まり・早生まれ対応）、保険料、既存の借入、ライフイベント、住宅費
- **住宅費の切り替え**: 購入前は家賃。購入月（＋設定した重複期間）以降は家賃を計上せず、ローン返済＋固定資産税・都市計画税＋火災地震保険＋修繕積立（またはマンションの管理費・修繕積立金）＋駐車場
- **投資**: 現金と完全に分けて管理。NISAは年間枠（つみたて120万・成長240万）と生涯1,800万円を超える積立を計算に入れない。現役中に現金が不足しても投資を勝手に売らない（「不足」として表示）。退職後は「現金が予備資金を下回った分だけ売る」ルールを画面で明示し、オン・オフできる
- 金額は各月の項目ごとに円単位へ丸めて合計するため、月次→年次の集計、残高の増減は円単位で一致します（テストで確認）

### 2. 住宅ローン（`src/engine/loan.ts`）

- 元利均等・元金均等、ボーナス返済（借入額の0〜50%、6か月ごと・半年分の利率）
- 利息は 残高×年利/12 を1円未満切り捨て、元利均等の返済額は1円未満四捨五入、最終回で精算
- 変動金利は、金利が変わったときに12か月ごとに残高・残期間で返済額を再計算（125%ルールは適用しない＝厳しめ）。固定期間選択型は固定期間の終了時に切り替え
- 返済期間は完済80歳を超えない長さに調整

### 3. 推奨額の算出（`src/engine/recommend.ts`）

1. 購入しない場合の推移から、購入直前の現金を求める
2. 自己資金 = 購入直前の現金 ＋ 援助 − 引越し費用 − 手元に残す予備資金（購入後の毎月の支出 ×（段階の月数＋1か月））。手入力も可
3. 借入額を1万円単位で二分探索し、各段階の条件を満たす上限を求める（住宅取得総額 = 借入額 ＋ 自己資金 = 物件価格 ＋ 諸費用）
4. 段階の条件

| 段階 | ストレス | 条件 |
|---|---|---|
| 安心 | 変動金利 +2%（5年で上昇）、購入後の収入 −10%、運用は悲観（初期1%） | 購入〜退職: 現金 ≥ 毎月の支出×予備資金の2倍（初期6か月分）／退職後: 現金 ≥ 0 かつ 現金＋投資 ≥ 介護費用の平均×人数 |
| 標準 | 変動金利 +1%、運用は標準（初期3%） | 購入〜退職: 現金 ≥ 毎月の支出×予備資金（初期3か月分）／退職後: 同上 |
| 注意 | 想定どおり | 現金が一度も0円を下回らない |
| 危険 | — | 注意の条件も満たさない |

5. 「標準」の上限を **適正住宅予算** として表示。①借りられる目安（フラット35の総返済負担率 年収400万円未満30%・以上35%、審査金利 初期3.5%、完済80歳）を超える場合はそちらを上限にする
6. 1万円多く借りると崩れる月と、その年に何が増えた（減った）かを「根拠」として表示

返済負担率は補助指標として表示するだけで、推奨額の決定には使いません。年収倍率も使いません。

### 4. 住宅の比較（`src/engine/houses.ts`）

- 住宅ごとに、同じ家計で購入した場合を計算（取得総額、月の住宅費、購入から35年の住宅関連支出、購入後5年の平均余力、現金が最も減る時、段階）
- **家計との適合度**: 住宅ごとの試算で判定した段階 ＋ 予算の境目（安心・標準・注意の上限額）との距離
- **お金の評価**: 家計との適合度、維持費（最も安い候補を100とした相対評価）
- **住み心地・好み**: 立地・間取り・保証・売りやすさ・満足度（5段階評価）、住宅性能（断熱等級・耐震等級・C値から算出）
- 総合点は重み付き平均。資金不足（危険）や価格未入力の住宅は、点数に関係なく後ろに並べます（安い住宅が自動で1位になることはありません）

### 5. 信頼度

年金・購入時期・老後の生活費など、推奨額への影響が大きい項目が未入力（仮置き）のほど信頼度を下げ、仮置きした項目と値を一覧で表示します。手取り月収・現金・生活費・生年月が未入力のときは推奨額を出しません。

## 技術構成

| 採用 | 理由 |
|---|---|
| React 19 + TypeScript | 画面の状態管理。計算エンジンは React に依存しない純粋関数 |
| esbuild | 依存が少なく、ビルドが1秒以内。開発環境のネットワーク制限下でも検証できる構成にするため Vite から変更 |
| 手書きの CSS（デザイントークン） | スクロールしない画面を精密に組むため、Tailwind の代わりに CSS 変数で色・文字・余白を一元管理（ライト／ダーク対応） |
| グラフは SVG を自作 | 円グラフの大きさを固定、実寸で描画、オフラインで軽い |
| Web Worker | 推奨額の探索（約60回のシミュレーション）を画面の裏で計算し、入力の遅延を防ぐ |
| IndexedDB | 自動保存・バックアップ（使えない環境は localStorage → メモリ） |
| node:test + tsx | 計算エンジンの単体テスト（Vitest の代わり。追加の依存なしで実行できる） |
| Playwright | 実際のブラウザでスマートフォンの画面サイズの検証 |
| GitHub Actions / Pages | テスト → ビルド → 公開 |

```
src/engine/   計算エンジン（型・シミュレーション・ローン・推奨額・比較・税・出典）
src/storage/  保存（IndexedDB・JSON形式のバージョン管理・クラウド保存）
src/ui/       画面（React）
tests/        計算エンジンの単体テスト
e2e/          画面のテスト
scripts/      ビルド
```

## GitHub Pages への公開

1. このフォルダの内容をリポジトリ（このアプリは `HOP`）に push
2. GitHub のリポジトリ設定 → Pages → Source を **GitHub Actions** にする
3. `main` に取り込むか、Actions タブから「Test & deploy to GitHub Pages」を手動実行
4. テストがすべて通ると `https://<ユーザー名>.github.io/<リポジトリ名>/` に公開されます

ルーティングはハッシュ（`#home` など）、ファイルは相対パスのため、どのリポジトリ名でもベースパスの設定は不要です。

## データとプライバシー

- 入力は端末の IndexedDB に保存し、計算も端末内で行います。外部に送信しません
- claude.ai の公開ページとして開いた場合のみ、あなたのアカウントの本人専用の領域にも保存します（他の閲覧者は読めません）
- 夫婦での共有（別の端末間の同期・ログイン）は実装していません。安全な認証にはサーバーが必要で、GitHub Pages 単体では提供できないためです。JSON の書き出し・読み込みで受け渡しできます

## 未実装・制約

- 繰上返済の試算、夫婦共有（認証・同期）、AI による文章整理
- 住宅ローン控除の借入限度額は一次資料（国交省の別紙）を取得できなかったため解説資料で照合。初期設定では計算に含めません
- 住宅ローン控除の税額上限、固定資産税は概算です（源泉徴収票・納税通知書の値を入力すると置き換わります）
- 125%ルール・5年ルールは扱いません（返済額の増加を厳しめに見積もります）
- 表示する金額は試算です。審査結果・税制の適用・運用成果を保証するものではありません
